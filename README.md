# Anatomía Humana para Fisioterapeutas

Aplicación educativa para estudiantes y profesionales de fisioterapia.

## Compatibilidad
Android 9 en adelante.

## Características
- Atlas anatómico.
- Anatomía descriptiva.
- Anatomía funcional.
- Evaluación muscular.
- Neuroanatomía.
- Dermatomas y miotomas.
